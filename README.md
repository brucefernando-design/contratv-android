# ContraTV Player (Android Nativo - Kotlin)

Aplicación oficial para el servicio **ContraTV**, optimizada para **Android TV (Fire Stick, Onn TV, Cajas Chinas)** y **Teléfonos Móviles Android**.

## Características
- **100% Nativo en Kotlin** con arquitectura moderna (AndroidX, Corrutinas, ViewBinding).
- **Diseño estilo InnovaTV / IPTV Smarters**:
  - Navegación por control remoto (D-pad) en Smart TVs y cajas de TV.
  - Navegación táctil para teléfonos y tablets.
- **Reproductor de Alto Rendimiento**:
  - Motor **AndroidX Media3 (ExoPlayer)** con aceleración por hardware.
  - Soporte para HLS (`.m3u8`) y MPEG-TS en vivo.
  - Menú en pantalla (OSD) con cambio de formato (Fit, Fill, Zoom) y canales.
- **Servidor Integrado**:
  - Conectado directamente a `https://panelcontra.lovable.app` con la API de Xtream Codes (`player_api.php`).
